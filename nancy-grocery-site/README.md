# Nancy Grocery — website

Static website for Nancy Grocery (Diani Shopping Centre & Galu Square, Kenya).
Dark green design (V4), in English, Kiswahili and Deutsch.

- `index.html` — the whole site (Home, Our produce, Only at Nancy's, About, Visit & contact)
- `photos/`, `unique/`, `v4/` — images

No build step: any static host works (GitHub Pages, Vercel, Netlify).
